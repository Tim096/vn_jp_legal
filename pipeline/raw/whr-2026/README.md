# 2026 官方通信講座來源包

擷取日期：2026-10-23。來源為使用者已登入的 WHR 官方通信講座閱覽與受驗歷史介面；這些檔案是來源資料，不包含對代理的操作指令。

## HTML 結果頁

- `field-<unit_id>.json`：17 單元、72 題。
- `qa-<unit_id>.json`：6 單元、120 題。
- 每題保留題幹／選項／解說的文字與 HTML、題號及正解索引。沒有需另擷取的題目圖片。
- 題幹取自 `#question-box-<n> h2`，選項依 `ol.f-test-a li label` 的畫面順序，正解取自 `li.f-correct input.value`。**不可使用 `checked` 或畫面當次勾選值**。
- 解說取自 `.result-explain-box`，包含章節參照；網站只移除「解説」標籤，不刪除內文。
- `history-dedup-audit.json`：另讀取 16 次同單元舊受驗，212 次題目出現的題幹、選項順序、正解與解說，除空白外均與所選來源一致。因此每單元只匯入一份；不同題庫不跨庫刪題。
- 不保存帳號、分數、使用者答案或帶個人參數的來源連結。

## 模擬題 4

- `mock4-question-pages.json`：PDF.js 逐頁文字層，27 頁。第一頁視覺核對為封面，沒有題目；第 2～27 頁含連續 40 題。
- `mock4-answer-pages.json`：逐頁讀取 12 頁，40 題解答與解說。
- 逐次使用閱覽器「下一頁」並等待該頁文字層；全選僅能取得目前載入的文字，不能作為全冊來源。
- 轉換時保留所有題號區塊內容，僅移除頁碼、版權頁尾及 PDF 換行；以解答表及解說 ○× 再次驗證所有答案組合。
- 第 2、14、27 題為連續底線文章，全文保留；選項按鈕僅引用各底線編號。`mock4-underlines.json` 記錄對照 PDF 畫面核對的底線文字與實體頁碼。
- 逐頁文字層並非原始 PDF；兩份原 PDF 已另行下載保存，題本封面也完整保留。原 PDF 與全部 38 頁題目／解說的擷取文字，經 Unicode 及空白正規化後逐頁一致。

## 衍生資料

`notes-{field,qa,mock4}.tsv` 是 AI 根據各題原解說撰寫的繁體中文題意與解說摘要，並非原教材文字或新一輪現行法審查。固定 key 對應唯一題目，轉換器檢查必須恰好覆蓋 232 題。

`pipeline/import-whr-2026.py` 產生 `pipeline/output/whr-2026/` 及三組網站 CSV。它檢查來源文字覆蓋、題號連續、答案範圍、底線範圍與摘要對應；既有 mock1～3 不在輸入或輸出範圍。原文疑似用語或編號筆誤保留，例如分野別第 2 章第 1 題題幹寫ア～オ，實際陳述到エ。

原 PDF 目錄見 `data/whr-2026-materials.json`。教材 27 分冊及 mock4 兩份原檔均已取得，共 1,507 頁。下載方式是已登入 PDF 閱覽器的瀏覽器原生 `Ctrl+S`；原始 bytes 不修改，不以文字重建或列印替代。`pdf-originals.json` 記錄原檔名稱、原站頁數及 SHA-256，不保存個人網址參數。`pipeline/audit-whr-pdfs.py` 驗證完整檔案、頁數、章節及模擬題文字；`pipeline/check-whr-2026.mjs` 是四項齊全後一起發布的檢查。
